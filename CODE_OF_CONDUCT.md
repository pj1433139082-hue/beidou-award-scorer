# Code of Conduct

## Our standard

Be direct about the work and generous about the person.

Concretely, in this repository:

- **Critique the detection logic, not the contributor.** "This regex counts headers as rows" is welcome; "you clearly did not test this" is not.
- **Bring evidence.** A claim that a check mis-fires is strongest with the document snippet and the observed output.
- **Assume good faith about intent, not about correctness.** Both can be true at once.
- **No real submission data in issues or PRs.** Redact names, amounts, and company details; paste the minimum needed to reproduce.

## Not acceptable

Harassment, personal attacks, discriminatory language, sustained disruption, or publishing someone's private information.

## Scope

Applies to issues, pull requests, discussions, and any space where someone is representing this project.

## Enforcement

Maintainers may edit, lock, or remove contributions that violate this document, and may block accounts for repeated violations. Report concerns privately via the contact on the maintainer's GitHub profile.

## Attribution

This is a short project-specific policy, not a verbatim copy of the Contributor Covenant. Where the two differ, this document governs this repository.
