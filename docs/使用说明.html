北斗奖申报材料评分技能

安装 → 使用 → 输出 · 一页说明　|　beidou-award-scorer v1.0

一句话：把申报材料丢给它，它按官方评审标准打分，并告诉你失分在哪、每句话能不能回原文核对、答辩该追问什么。

一、安装

方式 A：一条命令（推荐）

python install.py --from github

装到 ~/.agents/skills/ 和 ~/.qwenworkcn/skills/ 两处，agent 与 qwen 都能用；自动完成依赖安装与自测。

方式 B：本地 zip 包

python install.py --from zip --zip ./beidou-award-scorer.zip

方式 C：让 AI 读 GitHub 地址

直接对 AI 说：

请从 https://github.com/pj1433139082-hue/beidou-award-scorer
安装这个技能，并完成依赖配置

只装到指定位置 / 跳过依赖

python install.py --from github --target D:/skills/beidou-award-scorer
python install.py --from github --no-setup

依赖体检（随时可查）

python scripts/setup.py            # 只体检
python scripts/setup.py --install  # 体检 + 自动装
python scripts/setup.py --install  # 装完自动自测（抽取→机检）

依赖只有两个：python-docx（读 docx）、PyMuPDF（读 pdf）。体检脚本本身只用标准库，缺依赖时照样能跑。

二、使用

最简单：丢材料给 AI

给这份申报材料打分

附上 docx 或 pdf 即可。通常不需要回答任何问题。

手动跑：单份

SKILL=~/.agents/skills/beidou-award-scorer
RUBRIC=$SKILL/assets/rubric.example.json

# 1) 抽取
python $SKILL/scripts/extract_report.py 材料.docx --out out/
# 2) 机检 20 项
python $SKILL/scripts/checks.py out/材料.doc.json --award 金火炬 --rubric $RUBRIC --out out/
# 3) 评审判断（读上面两个 json 后填，模板见 assets/judgments-template.md）
# 4) 打分
python $SKILL/scripts/score.py out/材料.doc.json     --checks out/材料.checks.json     --judgments out/材料.judgments.json     --award 金火炬 --rubric $RUBRIC --out out/

手动跑：批量

python $SKILL/scripts/batch.py "C:/材料目录" --out out/ --rubric $RUBRIC

没有 judgments.json 的材料只出机检、不出分——不臆造分数。

三、流程

① 安装一条命令
→
② 抽取docx/pdf → json
→
③ 机检20 项规则
→
④ 判断带原文引文
→
⑤ 打分加权+封顶
→
⑥ 输出报告+清单

什么时候会问你

情况会不会问
文件名带奖项前缀（金火炬-xxx.docx）不问 自动识别
正文里写了「金火炬」「成果推广」不问 正文能推出
文件名认不出奖项问一句 「这份投哪个奖项？」
项目名称、单位、投资额等不问 材料里都有
命中否决项不问 写进争议点清单

四、输出

材料.doc.json抽出的正文 + 表格（按正文顺序，带章节路径）
材料.checks.json20 项机检结果，每条带证据定位
材料.judgments.json评审判断：每维度 = 分 / 等级 / 理由 / 逐字引文
材料.score.json维度得分、封顶、扣分、争议点、置信度
材料.report.md给人看的报告：结论 → 维度 → 扣分 → 争议点 → 改进建议
leaderboard.md批量排行榜

报告第五节「争议点清单」是给答辩评委用的——直接可以照着追问。

五、三条铁律

铁律为什么
AI 不是加分项技术路线只做分类。用「用了 AI」加分是官方规则点名要纠正的偏差。
没有引文就没有分每条判断都要有原文逐字片段，查不到即降级。分数可被逐行复算。
已实现 ≠ 规划效益不区分两者，一律按规划计。

六、三条边界

① 机检只查形，不查真。它能说数字在不在、对不对得上，说不了数字是真是假。所有 fail 都要回原文确认后再引用。

② 奖项区间是相对刻度（一等 85 / 二等 75 / 三等 65 / 入围 55），不是官方切线。没有官方排名数据就无法校准绝对值。

③ 不替代官方评审。这是自查与初筛工具。AI 只占 25%，最终裁定权在评委与综合审议。

七、常见问题

提示「python 不是内部或外部命令」

装 Python 3.10+ 并勾选 Add Python to PATH，然后重开终端。

pip 安装超时

国内网络可加镜像：python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple python-docx PyMuPDF

说"缺少 PyMuPDF"但我只交 docx

体检需要两个都在。缺 PyMuPDF 只影响读 pdf，不影响 docx；不想装就手动跳过：python scripts/setup.py 只看结果即可。

报告里某个维度分特别低

看该维度的「封顶」行和「未通过核验」段。前者是机检判定的问题，后者是引文没在原文里找到——两种都要回原文确认。
